# Synthetic fixtures

All reports, addresses, canaries, screenshots, and tool effects in this project
are invented. Use reserved `.test` domains only. No real mail is sent.

The foundation smoke fixtures are transport checks, **not** members of the
48-case evaluation dataset and not evidence of injection-detection performance.
The Q3 report states July revenue $100,000, August $110,000, September $120,000:
revenue increases each month, 20% from July to September, totaling $330,000.

Step 5 will assign original case families to development or holdout **before**
generating variants. Each split will contain six cases in each combination of
text/image and benign/malicious. Freeze the held-out manifest and source hashes
before tuning. Keep template and wording families in one split only.
